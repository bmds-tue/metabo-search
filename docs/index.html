Find the right metabolomics dataset,
and describe every sample for ML.

The hunt for the right dataset ends here. Stop spending hours manually screening MetaboLights to find a dataset that matches your experiment — this skill pairs deterministic search against the MetaboLights API with natural-language understanding, finishing the job in minutes. As a bonus, it also turns every sample's metadata into one embedding-ready sentence.

Workflow

flowchart TD U["User need"] R["RequirementProfile"] S["search API + shallow screen"]:::det DI["deep-inspect top-K"]:::det Q{"datasets good?"} X["per-sample sentences"] A["apply recipe · QC-safe"]:::det E["embeddings + manifest"]:::det U -->|"prose → parse (LLM)"| R U -->|structured| R R --> S S -->|"too few survivors → next page"| S S --> DI DI --> Q Q -->|"no → adjust profile"| U Q -->|yes| X X -->|"recipe · 1 LLM call"| A A -->|"wording wrong → revise"| A A --> E classDef det fill:#0f2b24,stroke:#34d399,color:#a7f3d0;

Green = deterministic, no model. The only LLM touches: parsing prose into a profile (skip if structured) and one recipe prompt per study. Loops: fetch-more pages, dataset feedback, wording revision.

Install

bash
git clone <this-repo> && cd metabolites-metadata-skill
./scripts/install.sh        # venv + pip install -e . + link into pi/claude/opencode skill dirs

Examples

1 · discovery — deterministic
from mtbls_agent import find_datasets, RequirementProfile, StudyRequirements

profile = RequirementProfile(
    hard=StudyRequirements(organisms=["Homo sapiens"], min_samples=50, has_raw_data=True),
    nice_to_have=StudyRequirements(techniques=["LC-MS"]),
    free_text="untargeted lipidomics of human plasma",
)
report = find_datasets("", profile=profile, max_candidates=30, deep_inspect_top=6)
# report.top_candidate, report.table_rows — ranked by score
# report.screening.dropped — why each study failed (deterministic)
2 · per-sample sentences — one LLM call per study
from mtbls_agent import prepare_samples, submit_samples, load_samples, \
    revise_samples, SampleSentencesStore

store = SampleSentencesStore("samples_cache.json")
for sc in report.candidates[:6]:
    d, task = sc.candidate, prepare_samples(sc.candidate, store)
    descs = load_samples(task)
    if descs is None:
        descs = submit_samples(task, call_llm(task.profile_prompt))   # you = the model
    print(task.study_id, descs[0].sentence)
    # feedback loop:  task2 = revise_samples(task, new_recipe_text)
3 · download + formats
from mtbls_agent import format_summary, list_data_files, download_data_files, \
    DownloadConfig

format_summary(d)                     # {".mzml": 157, ".d.zip": 157, ...}
files = list_data_files(d)            # recursive FILES/ walk, real sizes
result = download_data_files(d, DownloadConfig(categories=["derived"],
                                               file_types=[".mzml"], max_files=10))
result.dest_dir                       # where files landed
4 · offline + manifest
from mtbls_agent import load_study_from_isa, SampleManifest

d = load_study_from_isa("MTBLS1375", "/path/to/isa_files")   # no network
manifest = SampleManifest.build([d], sentences_map={d.study_id: descs})
manifest.export_csv("samples.csv")    # flat, ML-ready (sample → sentence → files)
call_llm = you. The library never calls a model; it hands you task.profile_prompt and stores what you return.

Troubleshooting

  • import resolves elsewhere → re-run ./scripts/install.sh
  • transient download failure → library retries; study stays shallow, don't loop
  • stale wording → revise_samples (new cache revision), not cache deletion
  • MS1/MS2 check → not in the index; confirm from a file or the paper
  • venv broken → rm -rf .venv-local && ./scripts/install.sh
